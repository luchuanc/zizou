# 金铲铲玩法与横屏改造

调研时间：2026-09-25。目标是将《山海弈》改成适合横屏触控的完整单机自走棋，保留中国神话角色、美术与七位本地 AI。

## 资料与版本边界

- [官方公告区新手站攻略，2023-10-03](https://bbs.4399.cn/thread-view-tid-41755859)：参考对抗/野怪/选秀循环、共享卡池、装备合成与卸装、商店操作和侦察。该资料描述的是当时版本，不能作为现行赛季全部数值的依据。
- [腾讯开发者 App Store 页面](https://apps.apple.com/cn/app/id1478101301)：当前内容包含自然之力赛季与赛季特色增益，确认赛季机制会更换。本项目采用跨赛季经典玩法，而非声称复刻现行赛季所有规则。
- [Riot 13.23 版本说明](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-13-23-notes/)：交叉核查人口上限扩至 10、按等级分配商店费用概率、有限共享卡池。这是云顶历史版本，具体平衡数值在本项目单独定义。
- [移动端实战界面参考](https://www.iefans.net/info/v1405428.html)、[界面设置参考](https://www.ldmnq.com/forum/93741.html)：仅用于观察界面区域分配，不作为规则或现行数值来源。

## 界面与交互方案

视觉方向：深青石与铜金边框的神话竞技场，棋盘占据主要画面，信息浮于四周。

内容层级：中央棋盘负责布阵与战斗；上方负责阶段与时间；左右负责羁绊、装备与对手；底部负责经济和招募。

交互方向：拖动时显示落点/出售/穿戴反馈；升星与装备合成使用短促金光；战斗和结算保留可追踪的生命、法力、伤害信息。

## 玩法实施与完成门槛

- [x] 保持 24 英灵、14 羁绊、8 专属共鸣、7 个独立 AI。
- [x] 阶段编号与 PVE / PVP / 选秀循环，三个强化选择节点。
- [x] 共享有限卡池；购买、刷新、出售、淘汰正确占用/归还。
- [x] 9 备战位、最高 10 人口、等级概率、经验、利息和连胜败收益。
- [x] 装备散件合成、三装备槽、穿戴、出售返装、升星继承；战斗效果实际生效。
- [x] 选秀按血量顺序与 AI 共同挑选，获得英雄和装备，满席不丢奖励。
- [x] 三选一天命强化，AI 使用相同经济和装备规则。
- [x] 自动准备倒计时、暂停、立即开战、阶段推进、完整淘汰/夺冠。
- [x] 原有拖售、触控点选、布阵、存档、离线与中断恢复继续可用。
- [x] 规则测试、多局模拟和真实横屏浏览器验收通过，文档与实际一致。

以上已按当前代码与 [验收记录](../QA.md) 逐项完成。普通网页不能保证操作系统允许锁定方向，因此采用横屏提示与受支持浏览器的全屏/方向锁定，不将 CSS 旋转页面当作横屏适配。


## 本项目的具体规则与差异

| 机制 | 本项目落地 | 单机适配考虑 |
| --- | --- | --- |
| 开局 | 一星哪吒、5 灵石、玄铁剑与灵玉杖 | 让第一次购买、升星与装备操作可以直接体验；不设置开局抢跑 |
| 回合 | 三场入门野怪，随后每阶段七回合：对抗、选秀、野怪 | 阶段栏预告下一种回合；2-1、3-2、4-2 进入强化选择 |
| 对手 | 七个具备独立经济、卡池占用、装备和血量的 AI | 其余 AI 也真实模拟对战；奇数人数时使用不重复收支的镜像 |
| 棋盘 | 七列八行，双方各四行 | 手机端压缩地面纵深并保持角色比例，给远端角色头顶保留空间 |
| 备战与商店 | 九个备战格、五张牌；手机商店可收起，经验/刷新/金币常驻 | 拖棋子时商店替换为出售区域，价格统一由经济规则计算 |
| 装备 | 八散件与三十六成装，每单位最多三件 | 单机原创命名和数值；拖动或点选穿戴，库存或英雄身上合成 |
| 强化 | 十八项，三个选择节点，各选项可刷新一次 | 经济、经验、生命、装备和战斗属性均进入实际规则，AI 同样使用 |
| 选秀 | 九个携带装备的英灵，血量最低者先选；同血量随机次序 | AI 先手选择真实占用候选；手机以 3×3 面板明确展示可选项 |
| 满席奖励 | 有上阵空位先放入，能升星先合成，否则返还英雄费用并保留装备 | 避免单机选择界面因没有空格卡死；规则在满席时明确提示 |
| 节奏 | 准备 30 秒、结算展示 5 秒、可手动开战或暂停推进 | 弹窗、竖屏和后台不会消耗准备时间；战斗支持暂停与三档速度 |
| 存档 | v3 包含全部 AI、随机种子、装备与待选奖励，兼容 v2 | 战斗中断恢复到布阵，已经发放的金币、装备和战绩不重复领取 |
| 超时与终局 | 35 秒起压低续航并提高战斗强度；60 秒平局双方扣血 | 最后一人存活即结束；8-7 仍多人存活则按气血、胜局结算 |

人口经验、费用概率、各费用总张数、英雄/装备伤害数值保存在本项目数据文件，不宣称等同于腾讯当前赛季。棋盘、角色、头像符号、装备名称、强化与音乐沿用原创神话风格；没有复用金铲铲的角色图、音频或商标。

## 触控验收重点

1. 拖动越过阈值才进入出售/穿戴模式，普通点选仍打开单位操作。
2. 松手时再次校验阶段、所属与命中区域；取消事件不产生经济变动。
3. 出售后拦截浏览器合成 click，避免同一手势又招募下面的英雄。
4. 卡池、装备、强化与选秀先保存权威状态，再同步 UI；读取结果和刷新页面不重新派发奖励。
5. 竖屏时释放模态层并显示旋转引导，回到横屏恢复原选择面板；它不会被隐藏的弹窗遮住。

## 手机界面精修与特效（2026-09-25）

本轮补充查看 [金铲铲之战官网](https://jcc.qq.com/) 与 [腾讯 App Store 产品页](https://apps.apple.com/cn/app/id1478101301)，并参考 [2021 年移动端操作介绍](https://www.sohu.com/a/485184847_596879) 和 [2021 年可收起商店的界面说明](https://www.sohu.com/a/506399988_120099889)。历史文章只用于理解信息层级，不将其当作当前客户端固定布局。没有采用腾讯的图像或音效。

据此为本项目选择以下布局：手机优先展示棋盘，侧边保留阵容、羁绊、装备、排名、战绩入口；经验、刷新、灵石、开战与寻仙入口放到底部。寻仙在准备阶段展开、开战时收起；战斗中仍可手动招募，拖棋子时自动展示带售价的寻仙出售区。桌面维持完整侧栏与商店。

所有弹窗采用固定标题与 44 像素关闭按钮，操作与翻页按钮在固定底栏。装备按库存、散件、成装切换，英雄与内容多的清单分页；每页内容完整呈现，页面不需要滚动。较矮视口自动减少每页数量，横竖屏切换保留自选状态。天命、选秀、奇遇与终局均可先收起，再从“继续选择 / 查看结算”返回，不跳过任何奖励。

特效保持 24 位英灵的招式差异，用局部斩击、箭矢、冰棱、火弹、魂火、莲华与护盾表达攻击；只有雷电短暂连接目标。移除逐个目标铺开的持久锁链、重复施法圆环；限制同时存活的特效组为 48、范围技能重点命中为 3，跳字按单位节流。限制只作用于画面，技能范围、目标、伤害与随机判定均沿用原有战斗规则。系统减少动态效果开启时降至 24 组并缩短弹道。

装备库存、合成配方、选秀、单位详情与棋盘上的装备统一使用原创器物图标，已纳入离线缓存和子路径部署资源地址。
