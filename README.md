# 山海弈

原创中国神话题材的单机自走棋。采用 **PixiJS 8 + TypeScript + Vite**，采用手机横屏布局，同时支持桌面、触控操作和 PWA 离线缓存。经典自走棋机制与界面区域的调研记录见 [设计与调研](./docs/金铲铲调研与改造.md)。

一局由玩家和七位本地 AI 组成。每位弈者独立经营灵石、人口、阵容与法宝；失败扣除气血，气血归零淘汰，最后一位存活者获胜。无需登录、服务器、联网匹配或付费接口。

## 启动

已在 Node.js 20.20.2 上验证。

```sh
npm ci
npm run dev
```

开发地址为 `http://localhost:5173`。同一局域网的手机可以使用终端列出的 Network 地址访问。开发服务不注册离线缓存。

```sh
npm test         # 核心规则、状态恢复、AI 与完整对局测试
npm run simulate # 16 局、8 种流派的模拟与平衡性数据
npm run build   # TypeScript 检查和静态构建
npm run preview -- --port 4173
```

生产预览为 `http://localhost:4173`。发布时将 `dist/` 部署到支持 HTTPS 的静态站点根目录。PWA 安装与离线缓存需要 HTTPS 或 localhost；手机通过局域网普通 HTTP 可试玩，但浏览器不允许此地址注册 Service Worker。此交付为网页版手游，未包含 Android APK 或 iOS 原生安装包。

## 当前内容

- **24 位英灵**：每位都有主动技能、被动能力、费用、阵营、职业和差异化属性。
- **14 类羁绊**：8 个阵营（昆仑、灵山、龙宫、月宫、青丘、九黎、蓬莱、幽冥）与 6 个职业（战将、守御、灵祝、术士、游侠、幻师）。同名棋子不重复增加羁绊人数。
- **8 组专属神话共鸣**：莲生沧海、日月同辉、创世双神、水火既济、天庭双圣、青丘双姝、冥府判官、神农百草。
- **阵容预选**：开局可选择昆仑天雷、沧海冰封等八套流派，也可从 24 位英灵中自选最多 10 位，或直接自由搭配。手机侧栏“阵容”入口可在局中更换、取消预选，阵容面板显示棋盘与备战席的收集进度；寻仙卡牌显示“核心推荐 / 补强推荐 / 自选推荐”，同时保留升星提示。预选不会改变商店概率或自动购买。
- **完整经营**：五格商店、费用与等级概率、刷新、锁店、9 格备战席、三合一递归升星、最高三星、修习升人口、出售、利息和胜败连局奖励。
- **18 种天命强化**：2-1、3-2、4-2 三选一，每项可单独刷新一次，整局生效。包含战斗、经济、经验、装备、续航等方向。
- **8 类散件、36 种成装**：44 个原创器物图标，库存、合成、选秀和棋子共用；库存或英雄身上两两合成，每位英灵三装备槽。出售返还装备，升星继承装备，多余装备退回库存。
- **阶段式对局**：1-1 至 1-3 野怪；后续每阶段第 4 回合共选仙缘，第 7 回合野怪，其余为对抗。选秀由低血量弈者优先，与 AI 共享九个带装备的英雄。
- **有限共享卡池**：八位弈者共同占用商店与持有英雄的库存，出售、刷新、淘汰返还。等级决定五档费用概率，可在商店上方查询。
- **横屏 HUD**：八行六角站位按屏幕高度重新分配纵深，角色保持原比例，预留后排状态与末排装备空间；青玉石台、铜色包边和敌我分界统一棋盘风格。姓名与装备合并一行，星级位于血蓝条侧；选中和拖动显示对应棋格，战斗时淡化棋格、收起多余标签，顶部显示双方存活数量。手机两侧为紧凑工具栏，九格备战席紧贴棋盘；底栏常驻等级经验、修习、灵石利息、刷新、寻仙、自动与开战。商店开战时自动收起，可随时展开；桌面保持完整侧栏。竖屏提示旋转并暂停推进。
- **无需滚动的弹窗**：固定标题、关闭与操作栏，内容按主题或数量分页；矮屏自动减少每页数量。天命与选秀可收起查看棋局，再从底部继续选择，待选奖励不会被跳过。
- **战斗机制**：六角寻路、目标优先级、远程普攻、法力、范围伤害、真实伤害、护盾、治疗、回春、灼烧、冰冻、魅惑、缓速、破甲、嘲讽、拉人、斩杀、召唤和一次性复苏。
- **原创视听**：青绿山水背景、三张透明角色图集；箭矢、火弹、冰棱、狐火、短促雷电、命中粒子、莲华与护盾等实时特效，同屏密度受控；程序生成的五声音阶音乐与音效。
- **完整局内流程**：侦察、排名、回合战绩、其他 AI 对局结果、淘汰、夺冠、最终阵容、本机战绩和重开。
- **操作与恢复**：鼠标/触控点选、拖动、独立布阵面板、30 秒自动准备、暂停推进、立即开战、战斗暂停、1/2/3 倍速、自动存档、异常存档校验。

## 如何游玩

1. 开局先预选阵容，也可选择“自由搭配，先入局”。点击流派查看成员与站位建议，再确认预选；自选阵容需点击“启用”后生效。选阵期间暂停计时，局中可通过左侧“预选阵容”更换。初始拥有一位哪吒、5 灵石与两件基础装备，招募两位哪吒可体验自动升为二星。
2. 新招募的英灵进入备战席。点选英灵再点击己方棋格即可上阵，也可拖动棋子，或点击备战席右侧的布阵按钮。
3. 人口已满时可以交换棋子；将上阵英灵拖回备战席可下阵。将备战席或棋盘上的己方英灵拖到底部整排操作按钮区域，整条底栏会显示名字、星级与售价，进入后显示“松手出售”；松手返还灵石与装备，移出底栏、取消触摸或按 Escape 取消出售。商店不再承担拖售，也不会因拖棋子自动打开。也可点选英灵后点击“出售”，或从详情、布阵面板操作。准备阶段可出售任意己方英灵；战斗中仍可招募、刷新、买经验和出售备战英灵，上阵单位不能出售或换装。
4. 同一阵营/职业的不同英灵会激活羁绊。点击羁绊、共鸣、图鉴或流派查看效果。
5. 每 10 灵石提供 1 点利息，上限 5；4 灵石可修习 4 阅历。战斗结算另得 2 阅历，最高 10 人口。初始试炼基础收入为 2/3/4，其后基础收入 5；对抗胜利 +1，连胜败 2/4/6 场额外获得 1/2/3。野怪不改变连局，选秀不额外发放收入。
6. 点击当前对手或排行榜可以侦察；适时把后排移开钟馗的魂锁，或用神农化解灼烧。
7. 准备时间为 30 秒，可点击立即开战；也可暂停自动推进，自由思考和手动开战。英灵自动行动，法力到 100 自动释放技能。战斗结果停留 5 秒后进入下轮，打开详情、竖屏或切到后台会暂停自动推进。
8. 开战 35 秒后进入天劫：双方攻速提高 40%，伤害逐步增长，治疗与新护盾减半；45 秒后续航效果仅保留 25%。60 秒双方仍有存活单位则判平局，对抗双方均扣除按敌方存活英灵计算的气血。
9. 气血归零淘汰。若到 8-7（内部第 52 回合，含选秀）仍有多人存活，则依次按气血、胜局排名；玩家与对手完全同分时玩家优先；AI 之间完全同分按座次排序。

## AI 设计

AI 使用同样的英灵、共享卡池、商店概率、货币、升星、人口、装备、战斗与奖励规则，不读取未来随机数，不修改战斗伤害。

- 每局洗牌分配八种流派中的七种，设有均衡、积蓄和进攻三种经济倾向。
- 对招募按核心流派、现有重复棋子、升星机会、空缺人口、成本和利息门槛排序。
- 血量危险或进入后期会降低存钱门槛，主动刷新补强；卖出部分不属于计划的低星余牌。
- 使用有限宽度搜索比较阵容的单卡强度、星级、羁绊、专属共鸣和前后排结构，而非简单挑最贵的棋子。
- **初游**围绕自身阵容发展；**问道**额外参考玩家已公开阵容，针对法师、灼烧、后排与魂锁选择反制棋子或站位。可在设置 → 重新开始时选择。
- AI 根据星级、角色定位分配装备，并在选秀中比较成型羁绊、升星机会与装备收益。强化既影响战斗，也真实结算金币、经验和装备。
- 其余对手也使用相同战斗模拟器交战；野怪回合每位 AI 独立挑战。人数为奇数时，落单 AI 挑战镜像；镜像不重复获取金币或承受伤害。
- AI 的“智能”是可解释的本地策略与搜索，不依赖在线大模型。

## 存档与离线

每次有效操作都会保存到浏览器的 `localStorage`。存档包括全部 AI 的经济、阵容、随机种子、淘汰状态、装备、待选强化、选秀进度、预选阵容与自动推进设置。

- 战斗中关闭/刷新，回到该轮的布阵阶段。
- 结算后刷新仍显示同一结果，金币和气血不会再次结算。
- 强化刷新、强化选择与选秀选择后立即存档，重复选择不生效。
- 预选阵容随本局保存，刷新与离线游玩保留推荐，重开时重新选择；旧 v3 存档自动补齐预选字段并保留原进度。
- v3 自动迁移 v2 对局并保留旧存档备份；旧事件仅作为迁移兼容保留，新对局使用阶段式选秀与装备掉落。
- 存储被浏览器禁止时，游戏仍可运行，页底提示存档不可用。
- 首次生产版本完整缓存后可断网刷新游玩。清除浏览器站点数据会同时清除缓存、存档和战绩。
- 不同端口、浏览器、设备有各自的本地存档，不做跨设备同步。

## 发布平台

可接入 <https://github.com/luchuanc/publishing>：分支 `main`，安装 `npm ci`，构建 `npm run build`，产物 `dist/`。平台为游戏提供独立端口或独立域名，部署在站点根路径。联网刷新时优先读取已发布文件，断网时仍可读取离线缓存，发布/回滚不清除本地存档。
